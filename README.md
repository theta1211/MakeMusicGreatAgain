# MakeMusicGreatAgain

Android ネイティブの音楽制作アプリ(シンセサイザー / ドラム / ギター等の音源、Bluetooth キーボード対応、スマホ・タブレット両対応)。

| [02. 要件定義](docs/02_requirements.md) | 対象環境、機能要件(優先度付き)、非機能要件、未決事項 |

| [04. ロードマップ](docs/04_roadmap.md) | PoC から MVP リリースまでの段階計画 |
