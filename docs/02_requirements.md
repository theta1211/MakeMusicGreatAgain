# 02. 要件定義

## 1. 目的・コンセプト

スマートフォンやタブレットだけで、シンセサイザー・ドラム・ギターなどの音を鳴らし、曲を作れるようにする。画面のタッチだけでなく、Bluetooth キーボードをつないで演奏・入力できるようにする。

## 2. 想定ユーザー

**メインターゲットは音楽制作の初心者**。専門用語を知らなくても、数分で 1 曲(ループ)を作れることを最優先にする。

| ペルソナ | 利用シーン |
|---|---|
| 初心者・趣味の人(**主対象**) | スマホで手軽にビートやフレーズを作る |
| 鍵盤を持っている演奏者 | BLE-MIDI 鍵盤をタブレットにつないで音源として使う / 録音する |
| 外出先で作曲する人 | 移動中にスマホでアイデアをメモし、家でタブレットで仕上げる |

## 3. 対象環境

| 項目 | 要件 |
|---|---|
| OS | **Android 7.0(API 24)以上**。targetSdk 36(Android 16、2026 年 8 月以降の Google Play 要件) |
| 端末 | スマートフォン、タブレット、折りたたみ端末、Chromebook。縦横両対応 |
| CPU | arm64-v8a、armeabi-v7a、x86_64 |
| 推奨 | `android.hardware.audio.low_latency` 対応機種 |
| 言語 | 日本語、英語 |

> **できるだけ多くの機種で動かす**方針のため、minSdk を 24 にする(Oboe が古い端末では OpenSL ES に自動で切り替える)。詳細は [07. 対応機種・対応キーボード方針](07_device_compatibility.md)。

## 4. 機能要件

優先度: **M** = MVP に必須、**S** = 早期に追加、**C** = 将来

### 4.1 音源(インストゥルメント)
| ID | 要件 | 優先度 |
|---|---|---|
| F-SND-01 | シンセサイザー(減算合成: OSC×2 + ノイズ、フィルター、ADSR×2、LFO)。プリセット 20 種以上 | M |
| F-SND-02 | ドラム音源(サンプル方式)。キット 3 種以上(アコースティック / エレクトロ / 808 系) | M |
| F-SND-03 | ギター音源(クリーン / ディストーション)。サンプル方式 | M |
| F-SND-04 | ベース、ピアノ、ストリングス音源 | S |
| F-SND-05 | ユーザーが SoundFont(SF2)を読み込める | S |
| F-SND-09 | 同梱音色は**無料素材(CC0 / パブリックドメイン / MIT / CC-BY)と自前の合成音のみ**。クレジット画面を設ける | M |
| F-SND-10 | 追加音色パックを無料でダウンロード(Play Asset Delivery) | S |
| F-SND-06 | エフェクト: リバーブ、ディレイ、ディストーション、EQ、コンプレッサー | M(リバーブ・ディレイ)/ S(その他) |
| F-SND-07 | 物理モデリングのギター(Karplus-Strong) | C |
| F-SND-08 | 自分で録音した音をサンプラーで使う | C |

### 4.2 演奏入力
| ID | 要件 | 優先度 |
|---|---|---|
| F-IN-01 | 画面の鍵盤で演奏(マルチタッチ和音、オクターブ切替、鍵盤幅変更) | M |
| F-IN-02 | ドラムパッド(4×4)で演奏 | M |
| F-IN-03 | **BLE-MIDI キーボードの検出・接続・演奏**(ノートオン/オフ、ベロシティ、ピッチベンド、モジュレーション、サスティン) | M |
| F-IN-04 | **Bluetooth PC キーボード(HID)で演奏**(キー → 鍵盤の割り当て、オクターブ切替) | M |
| F-IN-05 | USB-MIDI キーボードで演奏 | S |
| F-IN-06 | 一度接続した BLE-MIDI 機器へ自動で再接続 | S |
| F-IN-07 | MIDI チャンネルごとに別の音源を鳴らす(マルチティンバー) | S |
| F-IN-08 | MIDI CC を音色パラメータに割り当てる(MIDI Learn) | C |
| F-IN-09 | ギター用のコード / ストラム入力 UI | S |

### 4.3 作曲(シーケンサー)
| ID | 要件 | 優先度 |
|---|---|---|
| F-SEQ-01 | トラック: 最大 8 トラック(MVP)、各トラックに音源 1 つ | M |
| F-SEQ-02 | ドラム用ステップシーケンサー(16 ステップ、パターン長可変) | M |
| F-SEQ-03 | ピアノロール(ノートの入力・移動・長さ変更・削除、クオンタイズ) | M |
| F-SEQ-04 | リアルタイム録音(鍵盤 / MIDI 鍵盤の演奏を記録)、カウントイン、メトロノーム | M |
| F-SEQ-05 | テンポ(40〜240 BPM)、拍子、ループ範囲 | M |
| F-SEQ-06 | 元に戻す / やり直し | M |
| F-SEQ-07 | パターンを並べて曲にする(ソング / アレンジ画面) | S |
| F-SEQ-08 | スウィング、ベロシティ編集 | S |
| F-SEQ-09 | オーディオトラック(マイク録音) | C |

### 4.4 ミキサー
| ID | 要件 | 優先度 |
|---|---|---|
| F-MIX-01 | トラックごとの音量、パン、ミュート、ソロ | M |
| F-MIX-02 | トラックごとのエフェクト(インサート 2 つ)、センドリバーブ / ディレイ | S |
| F-MIX-03 | マスターのリミッター(音割れ防止) | M |

### 4.5 プロジェクト・書き出し
| ID | 要件 | 優先度 |
|---|---|---|
| F-PRJ-01 | プロジェクトの保存・読み込み・複製・削除、自動保存 | M |
| F-PRJ-02 | WAV 書き出し | M |
| F-PRJ-03 | M4A(AAC)書き出し、他アプリへの共有 | S |
| F-PRJ-04 | MIDI ファイル(SMF)の書き出し・読み込み | S |
| F-PRJ-05 | クラウドバックアップ | C |

### 4.6 初心者向け機能
| ID | 要件 | 優先度 |
|---|---|---|
| F-BEG-01 | **テンプレート**(ジャンル別: ヒップホップ / EDM / ロック / ポップ / Lo-fi)から始められる。ドラム・ベース・コードが入った状態で開く | M |
| F-BEG-02 | **スケール固定**: 選んだキー・スケールの音だけを鍵盤に表示(外れた音が出ない) | M |
| F-BEG-03 | **コードパッド**: ボタン 1 つで和音を鳴らす(I / IV / V / vi 等をキーに合わせて自動配置) | M |
| F-BEG-04 | **自動クオンタイズ**(録音したノートを拍に合わせる)を初期状態で ON | M |
| F-BEG-05 | ドラムパターンのプリセット(ジャンル別 50 種以上)をタップで適用 | M |
| F-BEG-06 | 初回起動時のチュートリアル(3 分以内、スキップ可) | M |
| F-BEG-07 | **かんたんモード / 詳細モード**の切り替え。かんたんモードでは音色エディターの細かいパラメータを隠し、「明るさ」「広がり」など分かりやすい 4〜6 個のつまみにまとめる | M |
| F-BEG-08 | 専門用語にはヘルプ(? アイコンで説明)を付ける | S |
| F-BEG-09 | 音色を「ジャンル」「雰囲気」で探せる | S |
| F-BEG-10 | アルペジエーター(押さえた和音を自動で分散演奏) | S |

### 4.7 設定
| ID | 要件 | 優先度 |
|---|---|---|
| F-SET-01 | オーディオ設定(バッファサイズ、レイテンシ表示・測定) | M |
| F-SET-02 | MIDI 機器の管理(接続 / 切断 / 入力チャンネル) | M |
| F-SET-03 | PC キーボードのキー割り当て変更 | S |
| F-SET-04 | Bluetooth 音声出力時の遅延警告 | M |

## 5. 非機能要件

### 5.1 性能
| ID | 要件 | 目標値 |
|---|---|---|
| NF-PERF-01 | 出力レイテンシ(低レイテンシ対応機種) | 20ms 以下 |
| NF-PERF-02 | 出力レイテンシ(それ以外) | 50ms 以下を目標、実測値を表示 |
| NF-PERF-03 | BLE-MIDI 打鍵から発音まで(低レイテンシ対応機種) | 40ms 以下 |
| NF-PERF-04 | 同時発音数 | 高性能機 64 / 中位 32 / 低価格 16(自動設定) |
| NF-PERF-05 | 音切れ | 8 トラック再生 + 鍵盤演奏時、10 分間でアンダーラン 0 回(中位機種) |
| NF-PERF-06 | UI の描画 | 60fps(鍵盤・再生位置表示) |
| NF-PERF-07 | 起動時間 | 2 秒以内に演奏できる状態 |
| NF-PERF-08 | メモリ | 同梱音色のみで 300MB 以下 |

### 5.2 使いやすさ
- スマホ(片手縦持ち)とタブレット(横置き)それぞれで最適なレイアウト。
- タップ領域 48dp 以上(鍵盤は除く)。
- 色だけに頼らない表示(色覚多様性)、TalkBack でメニュー操作が可能。

### 5.3 信頼性
- 予期しない終了時にも直前の自動保存から復元できる。
- オーディオ出力先の変更(イヤホン抜き差し、BT 接続)で落ちずに再接続する。
- BLE-MIDI 切断時に鳴りっぱなしの音を止める(全ノートオフ)。

### 5.4 セキュリティ / プライバシー
- ネットワーク通信なし(MVP)。個人情報は収集しない。
- BLE スキャンは `neverForLocation` を指定し、位置情報を取得しない。
- マイク権限は録音機能(将来)を使うときだけ要求する。

### 5.5 保守性
- 音声エンジン(C++)と UI(Kotlin)を分離し、エンジンは単体テスト可能にする。
- 音色素材のライセンス台帳を管理する。

## 6. 対象外(MVP では作らない)
- オーディオ録音 / 編集(マイク・ライン入力)
- AUv3 / VST のようなプラグイン読み込み
- 複数人での共同編集、オンライン共有
- iOS 版

## 7. 決定事項

| # | 項目 | 決定 | 反映先 |
|---|---|---|---|
| 1 | Bluetooth キーボードの種類 | **BLE-MIDI 鍵盤と PC 用キーボードの両方**を必須(M)で対応 | F-IN-03、F-IN-04、[07 章](07_device_compatibility.md#5-対応キーボード) |
| 2 | 主な利用者 | **初心者** | 4.6 初心者向け機能 |
| 3 | 音色の調達 | **無料素材のみ**(+ 自前の合成音) | F-SND-09、[06. 無料素材](06_free_assets.md) |
| 4 | 対応機種 | **できるだけ多くの機種・キーボードに対応** | minSdk 24、[07. 対応機種](07_device_compatibility.md) |
