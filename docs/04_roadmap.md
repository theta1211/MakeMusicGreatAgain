# 04. 開発ロードマップ(案)

期間は 1〜2 名での開発を想定した目安です。

| フェーズ | 期間目安 | 内容 | 完了条件 |
|---|---|---|---|
| **0. PoC** | 2〜3 週 | Oboe でシンセ音を出す / 画面鍵盤 / BLE-MIDI 鍵盤と HID キーボードで発音 / 実機レイテンシ計測 | 主要 3 機種以上で打鍵→発音の遅延を実測し、目標値の妥当性を判断できる |
| **1. エンジン基盤** | 4〜6 週 | コマンドキュー、シーケンサー、シンセ完成、ドラムサンプラー、SF2 再生、ミキサー、リミッター、オフラインレンダリング | C++ 単体テストが通る。8 トラック同時再生で音切れなし(中位機) |
| **2. UI(MVP)** | 6〜8 週 | ホーム、スタジオ、ステップシーケンサー、ピアノロール、ミキサー、設定。Compact / Expanded 両レイアウト | スマホ・タブレットで曲を作って WAV に書き出せる |
| **3. 仕上げ・β** | 3〜4 週 | プリセット・音色の整備、自動保存、エラー処理、端末マトリクステスト、クローズドテスト配布 | クラッシュ率 1% 未満、主要機種で NF 要件を満たす |
| **4. リリース後** | — | M4A / MIDI 書き出し、ソング画面、USB-MIDI、SF2 読み込み、MIDI Learn | — |

## 次のアクション
1. [要件の未決事項](02_requirements.md#7-未決事項確認したいこと)を確定する
2. 検証用の実機と BLE-MIDI 鍵盤を用意する
3. フェーズ 0(PoC)のプロジェクト雛形を作成する
